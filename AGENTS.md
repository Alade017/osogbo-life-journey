# Project workflow

Develop and build this project locally in VS Code using React, TypeScript, TanStack Start, Vite, Tailwind, and Supabase.

For new features, present the architecture and game-loop plan first and wait for explicit approval before editing files. Preserve server-authoritative RPCs, existing design tokens, and the user's current work. Do not rewrite published Git history. Validate changes with appropriate tests, type checking, lint, and builds.
