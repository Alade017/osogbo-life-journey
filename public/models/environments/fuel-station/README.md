# Filling station forecourt

- `filling-station-forecourt.glb`: a forecourt with canopy, pump islands, kerbs, a car and a squeegee bucket.
  Optimised from the supplied 3D Assets model (3.8 MB) to 1.58 MB: pruned, deduplicated, flattened, joined,
  quantized and meshopt-compressed. Real size about 18.2 m × 6.4 m × 16.7 m, Y-up, metres.
- Licence: CC0 1.0 Universal (`licenses/CC0-1.0.txt`), the licence supplied with the model.
- Used by the `fuel-and-go` venue in `src/lib/location-venue-designs.ts`. The venue fits the model to its stage footprint.
