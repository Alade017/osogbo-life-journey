# Dental practice kit (restyled for OSUN LIFE)

Source: "dental-practice-floor" model from 3dassets.dev (generator `3dassets.dev ingest`), licence CC0 1.0 Universal (`licenses/CC0-1.0.txt`). No attribution is required.

Each file is one prop, centred on the floor at its origin (metres, Y-up). Materials are recoloured to the OSUN LIFE palette in `src/components/3d/world-theme.ts`. Clinical equipment is excluded. The files are meshopt-compressed with merged primitives and quantized positions; load them with `MeshoptDecoder`.

`manifest.json` lists each file's size in metres and its compressed byte count.
